# Security

The collector's address and its publishable key appear in this repository
on purpose. That key can only read the collector's public tables, which
hold the same data the project publishes. It cannot write or delete.

If you find a way to write to the collector, to read anything that is not
meant to be public, or a secret committed by mistake, please report it
privately through GitHub's "Report a vulnerability" button on the
repository's Security tab, and do not open a public issue. We will answer
as soon as we can.
